# Windows v0.9.0 使用说明

本次将独立 Web 版适合本地精读的功能迁移到原生 Tkinter 界面。Windows 程序仍直接读取本机书库，不需要启动 Web 服务。

## 从哪里打开

解压 `downloads/Kandu-v0.9.0-win64.zip`，打开 `Kandu/Kandu.exe`。开发目录也可运行 `dist/Kandu/Kandu.exe`；请保留同目录的 `_internal` 文件夹。默认个人数据在 `%LOCALAPPDATA%\KanduDesktop`，升级程序无需搬动现有书库。

旧版截图仍保留在 README，界面新增入口以本说明为准。功能迁移不包含桌面与 Web 数据自动同步。

## 思考强度与模型来源

设置 → 编辑某个 LLM → 思考强度，可选默认、关闭、低、中、高。每个模型单独保存；默认保持原来的任务设置：DeepSeek 常规生词、查词、句解关闭思考，深入复核默认中等思考，其他模型沿用接口默认。手动设置覆盖任务默认，实际支持程度取决于模型接口。

生词、句解、查词等请求的状态栏显示配置名称和模型名称。生成生词每次优先尝试当前选定模型，失败后才尝试备用渠道；并行请求会分别显示来源。词表底部显示最近一轮生成尝试的模型，旧缓存没有来源时不补造。这里显示的是客户端实际发送的配置，不验证中转站最终使用的后端模型。

## 句子讲解与查词

- 双击句子，讲解使用标题、所在段落及相邻段落上下文。等待窗口缩小至正文旁边，完成后回到中央；可继续阅读。
- 句解窗口可“重新讲解”“深入复核”或“停止”。重新讲解失败保留已有结果；关闭或停止后的迟到结果不会覆盖新请求。
- 右键单词或选中的 2–3 词短语，选择“查词并收藏”。先显示离线词典，再由当前模型解释本文义、用法与句子译文。超过 3 词的内容使用句子讲解。
- 本文解释保存到生词本“最近来源”，个人编辑的释义和笔记保留。查词等待期间删除词条，迟到的解释不会重新收藏。
- 本文词表里的生词以淡色背景标出，支持常见复数、过去式、进行式以及短语变化。悬停一秒或点击可看解释、加入个人生词本。
- 段落或全文生词窗口可独立检查短语；再次点击允许复查。普通生词已生成不代表重点短语已经单独检查过。

## 计时与统计

阅读页底部显示计时、暂停和标记已读。标记已读立即停止计时；可再次改回未读，或点击“重读计时”。查词、句解及文章讨论窗口算理解时间；生成生词、手动暂停、切到其他程序、最小化以及两分钟没有操作时不计时。

首页“阅读统计”包括标题去重后的已读清单、全文词数、有效时间/速度、每日有效采样阅读量与速度曲线、连续天数及阅读来源。未读完文章也可以贡献有效采样和来源；历史记录没有计时依据时速度显示 `—`。速度至少需要 30 秒和 20 词采样。

实际阅读词数采用保守估算：普通阅读前进计入有效采样，拖动滚动条、搜索跳转不把跳过内容记作阅读量。明确标记已读后，该文章按全文词数计入累计实际阅读量；同标题重复刊物取一次，未完成时取最大单个来源的估算。每日曲线显示当日有效采样词数，因此不一定等于当天标记已读文章的全文词数。

采样定期保存，关闭阅读页前补存一次。统计刷新先等待本机已排队的采样写入，再汇总。

## 摘要去重、未读数与标签

摘要页默认隐藏更早刊物出现过的同标题文章，可勾选显示重复文章。首页文章数、未读数与该筛选采用同一口径。同一天的不同格式版本不互相隐藏。

摘要卡片点击“标签”编辑，用逗号分隔；最多 8 个，每个不超过 24 字。标签可搜索，也可用右侧下拉框筛选。最近阅读入口和已读/未读标记继续保留。

## 导入 Lex Fridman Podcast

首页点击“导入播客”，选择最近 1–50 期，或填写官网 Transcript 链接（每行一条）。仅导入官方 Transcript 文本，默认生成整期中文摘要，不自动生成生词。首次取官网系列图片，失败时使用本地简洁封面。

同一播客系列在首页显示为一本书，每期对应目录的一篇文章。重复导入会复用已保存文本和摘要，失败部分可补缺；“停止”保留已有成果。导入窗口执行中关闭会收起，重新打开可继续查看或停止。系列目录“补全节目摘要”避免重复启动；离开该目录会停止未完成的请求，已生成摘要保留。

导入会联网并使用选择的 LLM，可能产生 API 用量。官网结构变动或网络中断时会提示失败，可换模型或再次补缺。

## PDF 缓存与数据迁移

PDF 解析会根据页边、字体和标点判断跨页连续段落，保留真正的段落及文章边界。旧缓存升级前在该书缓存下生成 `before_pdf_paragraphs_v1` 备份，映射阅读位置、生词分段、会话引用和生词本来源；中断后可重试。若原文件还有其他正文变化，会停止升级并保留原数据。

`tools/export_reading_data.py` 与随包恢复脚本现在还包含 `reading-stats.json`、`reading-activity.sqlite3`、`article_tags`、`podcasts` 和节目原文。恢复保留目标电脑 LLM 配置，并备份目标原数据；不合并两份书库。导出包不含源电脑 API Key、模型配置或日志。恢复时请关闭桌面程序，具体命令见 README。

## 开发验证

在官方 CPython 3.12 64 位建立 `.venv` 并安装 `requirements.txt`。统一回归入口：

```powershell
.venv\Scripts\python.exe -B tests\run_tests.py
```

测试采用独立临时数据目录，阻止意外真实网络请求。`build_exe.bat` 生成 EXE、核对 PE 版本、隔离启动检查，并生成带许可证的免安装 ZIP。覆盖范围包括模拟模型、模拟播客官网、原生 Tk 布局与交互、计时/统计及 PDF 中断恢复；不把模型输出质量或官网未来改版视为自动测试保证。
